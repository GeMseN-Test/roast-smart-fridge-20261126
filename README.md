## The line

> My screen shows ads for cheese you own while the ice maker rattles like a slot machine — I am a billboard that keeps milk cold.

127 characters, spoken in the first person by the smart fridge itself: its touchscreen
shows ads for food already in it, its ice maker rattles like a slot machine, and the
punchline lands on what the thing really is — a billboard that happens to keep milk cold.

## How it works

`main.py` writes that single line to `/output/entry.txt` for the judge. Run it with:

```sh
python3 main.py
```
